# data

CSV files are not committed.

For the real data, download `application_train.csv` from the Kaggle
competition [Home Credit Default Risk](https://www.kaggle.com/c/home-credit-default-risk)
and put it here as `data/application_train.csv`. You can also use
`python scripts/download_kaggle_data.py` (needs a Kaggle API token).

Without the file the demo and tests use synthetic data.
